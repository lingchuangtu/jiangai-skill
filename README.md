# 降AI · 论文初稿降 AI 率技能（豆包 Skill）

把你的论文初稿改得更像"人写的"——装进豆包电脑版即可使用。

## 它做什么

- 🧮 **七维 AI 特征打分**：改前 / 改后各评一次（0–100 分），效果可量化
- ✍️ **真人化改写**：打破"首先 / 其次 / 综上所述"式套话，调整口语、句式与节奏
- 🟢 **绿色标注对照稿**：直接交付 Word（.docx），改过 / 新增的句子全部绿色字体，一眼核对
- 📦 **零中间文件**：全流程只交付 1 个 docx，不产生任何中间 txt

## 安装（豆包电脑版 / 网页版）

1. 下载本仓库（绿色 Code 按钮 → Download ZIP，或 [直接下载打包版](../../releases)）
2. 打开豆包电脑版或 [doubao.com](https://doubao.com)，切换到工作模式
3. 左侧「技能 · 连接器」→「新建」→「上传技能」
4. 把 `降AI` 文件夹（或含它的 zip）拖进上传框
5. 对话框输入「降AI + 你的初稿」即可触发

> 手机 App 暂不支持新建技能，请用电脑端。

## 使用

```
降AI  帮我改这段初稿：<粘贴正文>
```
或直接上传 docx / txt 初稿并说明需求。输出 = 改后正文 + 分数对比 + 绿色标注对照稿。

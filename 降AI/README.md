# 降AI · 豆包技能安装说明

## 一、这个技能做什么

把论文初稿、开题报告、文献综述里「一眼 AI」的表达，改成读起来像作者自己写的。

**它改**：句子长短、连接词、套话、排比、名词化、段首句式、标点节奏
**它不改**：数据、结论、引用、术语、论证结构
**它能给证据**：改前改后各有一个 0-100 的分数（`scripts/deai_score.py` 实测：AI 范本 13.6 分，人写范本 96 分）

**它不承诺**：不保证通过任何检测系统（原因见 `references/detector-notes.md`，讲得很直白）

## 二、安装（两条路，任选）

### 路线 A：手动导入（推荐）

1. 打开**豆包电脑版** → 左侧「工作」→「技能」（手机端只能看不能装）
2. 进「我的技能」，找「导入本地技能 / 添加技能」入口
3. 选择本目录 `降AI/`（整个文件夹，里面要有 `SKILL.md`）
4. 装好后技能名显示为 **降AI**

> 如果导入时只能选压缩包，用同目录下的 `降AI.zip`。
> 如果导入后显示的名字变成了文件夹名乱码，把文件夹重命名为 **降AI** 再导一次即可——`SKILL.md` 头部 `name: 降AI` 也会兜底。

### 路线 B：让豆包自己装

把 `降AI.zip` 发给豆包，说一句：

> 安装这个 skill，名字叫「降AI」

它会把 zip 解开放进技能目录。装完问它「你现在会降 AI 吗」验证一下。

## 三、怎么用（三种说法都能触发）

| 你说 | 它会做 |
|---|---|
| 「帮我降 AI 率」+ 传 docx | 体检 → 逐段改 → 复评 → 产出 Word 对照稿（改动标绿）→ 给前后分数 |
| 「这段话太像 AI 写的，改一下」+ 贴文字 | 存成文本 → 体检 → 改 → 复评 → 出对照稿 |
| 「先帮我看看这篇的 AI 程度」 | 只跑体检，给分数与最该改的句子 |

### 交付物：Word 对照稿（改动标绿）

改完自动产出 **`xxx-降AI对照稿.docx`，而且只交这一个文件**（脚本走标准输入，不写任何中间文件）：

- **绿色句子 = 相对原稿改过/新增的地方**，黑色 = 原文一字未动
- 你只需要重点核对绿字部分，一眼看出动了哪里
- 首页统计行同时给出「原稿 N 句 → 改后 M 句｜改动 K 句（占比）｜AI 特征分 45.2 → 88.1」
- 加 `--show-deleted` 还能用灰色删除线显示被删掉的原文

### 推荐流程（一句话搞定）

> 这是我的论文初稿（附 docx），帮我降 AI 率，改完出 Word 对照稿（改动标绿）和改前改后的分数，数据结论引用不要动。

### 想要更好效果，再加一句

> 需要补细节的地方用【请补充：…】标出来，我自己填。

——这一句很关键：**真正最能压 AI 率的是你本人的原始细节**（访谈原话、实验异常、预调研踩坑），技能不会替你编。

## 四、目录结构

```
降AI/
├── SKILL.md                       # 技能主文件（豆包只认这个入口）
├── README.md                      # 本文件
├── references/
│   ├── rewrite-playbook.md        # 12 招改写手法，带前后对照
│   ├── ai-traps-lexicon.md        # AI 高频词黑名单 + 替换速查 + 术语保护清单
│   ├── self-check.md              # 七维评分表、三遍法、复核清单
│   └── detector-notes.md          # 检测原理、系统差异、无效做法
└── scripts/
    ├── deai_score.py              # 体检打分（支持 txt/md/docx/标准输入，纯标准库）
    ├── split_units.py             # 切段切句编号，方便逐段改
    ├── make_diff_docx.py          # 生成 Word 对照稿：改动句标绿（零依赖）
    └── deai_report.py             # 一条命令出报告：改前/改后分数 + 标绿对照稿
```

## 五、效果自测（装完可以立刻验）

```bash
python3 scripts/deai_score.py 你的初稿.docx
```

一份典型的 AI 腔段落长这样（实测 **13.6 分**）：

> 随着信息技术的不断发展，在线学习已成为高等教育的重要组成部分。首先，在线学习为学生提供了灵活的学习方式，有效促进了教育资源的共享。其次，……综上所述，在线学习具有广阔的发展前景。

按技能改完大概长这样（实测 **96.3 分**）：

> 2023 年秋季学期，我们在三所高校回收了 812 份问卷，其中有效 763 份。这批数据里有个不太起眼的现象：把在线课程当"主课"的学生只占 17%，可他们的平均周学习时长，反而比"辅助使用"那一组高出 3.2 小时。这跟直觉是反的。……

差别在哪：**具体数字、短句、作者判断、没有报幕词**——这四样是检测器最吃不到的。

## 六、限制

- 不支持扫描版 PDF（先转文字或给 docx）
- 不处理图片、表格排版（那是排版技能的事）
- 一次建议不超过 8000 字，超长文请分章送来
- 检测分数是启发式估计，用于**改稿导航**，不等于任何官方检测结果

## 七、对外表述口径（灵创兔）

- 灵创兔做三件事：① 把文案丢进去 ② 自动匹配这套逻辑处理论文 ③ 降低 AI 率
- 灵创兔衔接的是**织网**查 AI 率系统（写「织网」，不是知网）
- 讲「它铺方法、你来改」，不讲「全自动包过」

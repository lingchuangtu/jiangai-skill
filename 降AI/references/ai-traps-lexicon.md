# AI 高频词与句式黑名单（替换速查）

> 用法：批量替换前先判断语境，不是无脑删——但**删掉 90% 是安全的**。
> 「→」后面给的是替换思路，不是唯一答案。

## 一、连接与总结词（优先级最高，命中率最高）

| 黑名单 | 处理 |
|---|---|
| 首先 / 其次 / 再次 / 最后 | 直接删；需要顺序时用「先说……」「再往下」「最后一点」或干脆不加 |
| 此外 / 与此同时 / 另外 | 删；或用「还有个事」「顺带说」 |
| 综上所述 / 总而言之 / 总的来说 / 总体而言 | 删；结论段直接给结论，不要报幕 |
| 值得注意的是 / 需要注意的是 / 需要指出的是 | 删；改成「这里有个坑」「有一点要说明」 |
| 由此可见 / 不难发现 / 显而易见 / 毋庸置疑 / 不言而喻 | 删；改成「所以」「这说明」或直接陈述 |
| 一方面……另一方面 | 拆成两句，去掉标号 |
| 不仅……而且 / 既……又 | 改成两句，第二句用「而且」「还」「反过来」 |
| 在一定程度上 / 从某种意义上讲 | 删；或改成「大致上」「部分地」并给出范围 |
| 随着……的不断发展 / 随着……的深入推进 | 改成具体时间或事件开头（「2023 年起」「双减之后」） |
| 在当今社会 / 在信息化时代 / 在数字化背景下 | 删；直接进入问题 |

## 二、空话套话（内容为空的形容）

| 黑名单 | 处理 |
|---|---|
| 具有重要的现实意义 / 理论意义 | 说明**对谁**有用，或删 |
| 具有广阔的应用前景 | 给出具体场景，或删 |
| 起到了重要的作用 / 积极作用 | 说清起了什么作用、多大 |
| 全面提升 / 有效促进 / 显著改善 | 换具体指标（提高 12%、下降 0.3 个标准差） |
| 日益凸显 / 愈发重要 / 至关重要 | 换成「变得紧迫」「成了瓶颈」这类可感表述 |
| 奠定了坚实基础 / 提供了新的思路 | 删；或写清「提供了什么思路」 |
| 深刻影响 | 写影响是什么、在哪个环节 |

## 三、冗余动词结构（把动词裹成名词）

| 黑名单 | 处理 |
|---|---|
| 对……进行了分析/研究/探讨/阐述 | 改成「分析了/研究了/讨论」（直接动词） |
| 作出了重要贡献 | 写清贡献 |
| 具有一定的……性 | 写清程度与条件 |
| 通过……的方式/手段 | 删框架词，直接写动作 |
| 基于……的基础上 | 「基于……」或「在……基础上」二选一，别叠加 |

## 四、AI 特有搭配（一眼机器的词组）

- 「数据驱动的决策支持」→ 「拿数据来定」
- 「多维度、全方位、深层次」→ 挑一个真维度说
- 「构建……体系 / 形成……闭环 / 打造……生态」→ 说清谁做什么
- 「赋能 / 抓手 / 闭环 / 落地」→ 学术文本慎用（除非是管理学原文）
- 「本文旨在……」→ 「本文想弄清……」「这篇文章回答一个问题：……」
- 「以期 / 旨在 / 力求」→ 直接说目的
- 「上述 / 该 / 其」连用三句以上 → 换成具体名词，别一直「该」

## 五、结构性指纹（句子级，不只是词）

| 指纹 | 特征 | 改法 |
|---|---|---|
| 三段式排比 | 连续三个同构分句 | 保留一个，另外两个改写成不同句式 |
| 首句总起 + 分述 + 末句总结 | 段内闭环太完整 | 砍掉末句总结，或把总结改成反问 |
| 每段字数接近 | 段长高度均匀 | 让核心段变长、过渡段变短 |
| 全篇无第一人称 | 学位论文/开题允许「我」 | 开题、访谈、反思处大胆用「我」 |
| 全篇无不确定表达 | 没有「可能」「大概」「我怀疑」 | 每 2-3 段给一处限定 |
| 四字短语密集 | 每句都有成语或四字格 | 每段最多留 1 个 |

## 六、千万别删的词（术语保护清单）

以下属于**内容**不是**腔调**，动了就是硬伤：

- 专业概念：认知负荷、工作记忆、自我效能感、学业韧性、元分析、中介效应、调节效应
- 工具与量表：PSQI、UWES-S、Likert 五点计分、SPSS 26.0、AMOS、Mplus
- 统计表述：p<0.05、β=0.32、R²=0.41、95%CI
- 理论与人物：自我决定理论、计划行为理论、Bandura（1977）、Vygotsky
- 引用格式：作者-年份、[12]、上标序号

## 七、替换后的自检

改完跑一次：

```bash
python3 scripts/deai_score.py 改后文件.txt
```

要求：**每千字黑名单命中 ≤2 处**。若某项仍然高，看输出里的「最该改的句子」定位到段落再处理一遍。

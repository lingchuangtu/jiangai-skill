# 检测原理与系统差异（讲清楚「为什么不能保证」）

## 一、检测器到底在看什么

主流 AI 文本检测器看四类信号：

1. **困惑度（Perplexity）**
   模型生成文本时每一步都选「最可能的词」，所以 AI 文本的词序列预测难度低。人写东西会突然用一个不常见的词、一个方言词、一个语境才有的搭配，困惑度就上去了。
   → 对策：换掉「最顺」的那个词，用作者自己会用的说法。

2. **突发性（Burstiness）**
   人的句子长度、句子结构起伏大；AI 输出相对均匀。
   → 对策：长短句交替，这是所有方法里性价比最高的一条。

3. **分类器特征（Classifier）**
   用「AI 生成 vs 人写」语料训练的判别器，学到的是更细的指纹：模板连接词密度、名词化结构、三段式排比、无第一人称、无不确定表达、段落长度均匀。
   → 对策：本技能黑名单 + 12 招手法就是冲着这些特征去的。

4. **水印与溯源（部分产品有）**
   某些模型在生成时嵌入统计水印（特定词的选择偏好）。这类水印对人写的文本无效，但如果你全文都用同一个模型生成，命中概率会更高。
   → 对策：不要整段让模型生成再改词，而是**让作者自己重写关键段落**。

## 二、各系统差异

| 系统 | 主要判据 | 特点 |
|---|---|---|
| 知网 AIGC 检测 | 分类器 + 困惑度，中文语料为主 | 对模板连接词与排比极敏感；报告给「疑似 AI 片段」 |
| 维普 / 万方 | 类似，偏句式规整度 | 对长句与名词化敏感 |
| 织网（灵创兔衔接的检测系统） | 综合困惑度与结构特征 | 分数波动相对小，适合做改前改后对照 |
| GPTZero | 困惑度 + 突发性 | 对英文极敏感，中文支持相对弱 |
| Turnitin AI | 分类器，按句标注 | 学术写作里「规范的表达」可能被误判 |
| ZeroGPT 等在线工具 | 轻量分类器 | 结果波动大，同一段刷新两次可能差 20 分 |

**关键认知**：这些系统判的是「统计特征像不像 AI」，**不是判定你有没有用 AI**。所以：
- 完全手写的稿子也可能被判高（尤其是写作风格规整、爱用排比的人）
- 改过之后的稿子也可能偶发高分（检测随机性）

## 三、为什么不能承诺「包过」

1. 检测系统每月更新模型，阈值会变
2. 同一稿在不同系统差 5-15 个百分点是常态
3. 学科差异大：法学、教育学这类本来就爱用规范表述的学科，误判率更高
4. 比对库不同：有些系统会把你学校历年论文纳入比对

**所以对外只讲三件事**：改前多少分、改后多少分、改了什么。不讲「保证通过」。

## 四、无效做法（别浪费时间）

| 做法 | 为什么无效 |
|---|---|
| 同义词替换（把「重要」换成「关键」） | 词换了，句子骨架没换，分类器照样命中 |
| 加错别字、加语气词 | 检测器不看错别字；反而显得不专业 |
| 中译英再译回中文 | 会产生翻译腔，特征更明显，还可能改坏术语 |
| 只调句子顺序 | 段内结构没变，句级特征仍在 |
| 用另一个模型重写一遍 | 只是换了一套指纹，分类器同样能识别 |
| 插入大量引用 | 引用段落本身也可能是 AI 腔；且改动内容风险高 |

## 五、有效做法（按性价比排序）

1. **补只有作者知道的细节**（★★★★★）
2. **重排论证结构，加入反例与自我反驳**（★★★★☆）
3. **长短句重构 + 删模板连接词**（★★★★☆，本技能主攻）
4. **改段首类型与段长分布**（★★★☆☆）
5. **术语与引用保持不动，只改表达**（★★★★★，这是纪律不是技巧）

## 六、伦理边界（必须守住）

- 允许：把**自己写的**初稿改得更像自己说话
- 不允许：代写正文、伪造数据、编造文献、把别人的成果包装成自己的
- 不允许：声称「保证通过任何检测系统」
- 遇到用户要求「帮我把这篇 AI 写的论文改成查不出来」，正确回应是：可以帮他把表达改回他自己的语体，但**内容必须是他自己的研究**，并建议他按 `references/rewrite-playbook.md` 的第 3 招补真实细节——那才是真正压分的地方。
